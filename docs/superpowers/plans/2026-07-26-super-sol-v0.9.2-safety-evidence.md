# Super SOL v0.9.2 Safety and Evidence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a `v0.9.2-rc1` candidate that leaves stock Codex silent by default, enforces only deterministic safety incidents, and records bounded privacy-safe evidence.

**Architecture:** A default-off quality-mode gate wraps the existing v0.9.1 semantic mechanisms. The loop fuse remains the default intervention engine, while a new immutable incident ledger and an opt-in benchmark test guard provide auditable safety evidence without persisting model content.

**Tech Stack:** Python 3.12, stdlib Codex hooks, pytest, Pydantic test adapters, Ruff, BasedPyright, uv.

## Global Constraints

- Default mode emits no model-visible context unless a deterministic safety policy denies or stops an action.
- No additional model call, retry, continuation, model substitution, effort change, or agent start.
- Raw prompt text, command text, tool output, file content, paths, environment values, and credentials are never persisted.
- Exact `gpt-5.6-sol` retains the v0.9 loop fuse; unsupported profiles pass through.
- `SUPER_SOL_QUALITY_MODE=selective` is the only semantic-quality opt-in.
- `SUPER_SOL_BENCHMARK_GUARD=1` is the only test-mutation guard opt-in.
- Production and test Python files stay at or below 250 non-comment, non-blank lines.
- `v0.8.0` remains stable; v0.9.0 and v0.9.1 evidence remains immutable.

---

## File Structure

- `plugins/super-sol/hooks/super_sol_modes.py`: parse the two explicit operating modes.
- `plugins/super-sol/hooks/super_sol_audit.py`: write immutable bounded incident events and compute counters.
- `plugins/super-sol/hooks/super_sol_benchmark_guard.py`: identify test-targeting edit requests without storing paths.
- `plugins/super-sol/hooks/super_sol_prompt_hook.py`: keep semantic routing behind quality opt-in.
- `plugins/super-sol/hooks/prompt_dispatcher.py`: preserve the silent fast path in safety-only mode.
- `plugins/super-sol/hooks/super_sol_evidence_hook.py`: suppress quality evidence context by default.
- `plugins/super-sol/hooks/super_sol_loop_hook.py`: record decisions and suppress soft warnings by default.
- `src/fablized_sol/eval/codex_telemetry.py`: classify known transient Codex infrastructure failures.
- `tests/plugin/`: cover default silence, explicit opt-in, audit privacy, and benchmark protection.
- `tests/eval/test_codex_telemetry.py`: cover 503 circuit-open and concurrency-limit censoring.

class QualityMode(StrEnum):
